# Succubus Plus 1.0.0.60 — тестовая версия

Класс суккуба для Baldur’s Gate 3 с тремя подклассами: Кошмар, Королева пауков и Искусительница.

- Развитие класса до 20 уровня, собственные дары и заклинания.
- Механики желания, экстаза, самообладания и чар.
- Крылья, особые реплики и взаимодействие с торговцами.
- Русский и английский языки.

Для работы нужен BG3 Script Extender. Для уровней 13–20 требуется мод, снимающий ограничение уровня. 5eSpells и Valkrana’s Spellbook необязательны. Оригинальный класс Succubus отдельно устанавливать не требуется; не включайте обе версии одновременно.

Версия проходит испытания: накопление желания подтверждено в игре, остальные механики и сочетания модов нуждаются в дополнительной проверке. Перед изменением набора модов сделайте резервную копию сохранения.

Вдохновлён модом Succubus — new class автора Viper_Rogue. Класс включает переработанные данные исходного мода. Succubus Plus разработан AdSyDe с помощью ИИ.

# Succubus Plus 1.0.0.60 — testing release

A succubus class for Baldur’s Gate 3 with three subclasses: Nightmare, Spider Queen and Temptress.

- Class progression through level 20, with gifts and spells.
- Desire, Climax, Discipline and Charms mechanics.
- Wings, dialogue options and trader interactions.
- English and Russian localisation.

BG3 Script Extender is required. A level-cap mod is needed for levels 13–20. 5eSpells and Valkrana’s Spellbook are optional. The original Succubus class is not required; do not enable both versions together.

This is a testing release: Desire accumulation has been confirmed in game, while other mechanics and mod combinations need further testing. Back up your saves before changing your mod setup.

Inspired by Succubus — new class by Viper_Rogue. The class includes adapted data from the original mod. Succubus Plus was developed by AdSyDe with AI assistance.
